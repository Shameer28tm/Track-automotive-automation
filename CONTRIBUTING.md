# Contributing

Thank you for helping improve Track Automotive Automation.

## Development workflow

1. Create a focused feature branch.
2. Keep changes scoped to one concern.
3. Build the solution with `dotnet build .\GarageManagementSystem.sln`.
4. Run relevant tests and exercise affected workflows locally.
5. Do not commit credentials, database files, user uploads, generated output, or local IDE caches.
6. Preserve license notices for third-party code and assets.
7. Describe behavior changes and validation results in the pull request.

## Reporting issues

Open an issue in this repository with a concise description, reproduction steps, expected behavior, actual behavior, and sanitized logs. Do not publish secrets or personal data.
